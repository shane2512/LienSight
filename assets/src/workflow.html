How it works · built on CRE
Liensight
Chainlink CRE workflow · every 10 minutes
1Trigger

Cron fires

The workflow wakes on schedule for one building (BBL).

CronCapability "0 */10 * * * *"
2HTTP capability

Nodes read ACRIS

Each node queries NYC Open Data on its own: legals, then master.

HTTPClient · 8h5j-fqxa + bnx9-e6tj
3Consensus

Identical or nothing

Nodes must return the same document set. Truncated or empty data fails closed.

consensusIdenticalAggregation
4EVM write

Signed report

Property key, doc-set hash, adverse and discharge IDs, ABI-encoded.

runtime.report → writeReport
On-chain · LiensightToken (Sepolia)
5Forwarder → onReport

Checks the sender

Only the CRE forwarder, the expected workflow owner and this property’s key are accepted.

onReport(metadata, report)
6Restrict

Transfers stop

A new adverse filing sets restricted and cites the lien. A cleared lien never re-restricts.

event Restricted(docSetHash, docIds)
7Issuer review

Clear, in public

Only the issuer multisig can clear, naming the exact liens it reviewed.

clearRestriction(citedHash, reason)
