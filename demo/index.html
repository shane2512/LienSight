How it works

One record, every node, three steps

  1. 1Every node reads the record. Each Chainlink CRE node queries NYC ACRIS for the property on its own.
  2. 2The network agrees. Nodes must reach consensus on the exact set of filings before anything is written.
  3. 3The token reacts. A new adverse filing pauses transfers and cites the document. Only the issuer can clear it, by naming the liens it reviewed.
