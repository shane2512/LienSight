How it's built.

A token, a workflow and an adverse map. Here is what each part does, how to run it, and where it stops.

01

The token LiensightToken.sol

An ERC-20 for shares in the company (SPV) that owns the building. It is not the title. The restriction comes from the issuer's own operating rules.

onReport(metadata, report)
Called by the CRE forwarder. Checks the workflow owner and the property key, then restricts if a cited lien is new.
clearRestriction(hash, reason)
Issuer only. The hash must match the liens it reviewed, so a lien that arrived mid-review can't be cleared unseen.
setExpectedWorkflowOwner(addr)
Issuer only. Moves the token from the simulator to a deployed workflow.
restricted · citedHash
Public state. Transfers revert with TransferRestricted() while restricted is true.
Tested

18 Foundry tests: access control, replays, cleared liens never re-restricting, stale clears reverting, gas for 20 liens at once.

02

The workflow Chainlink CRE.

A cron-triggered TypeScript workflow. Each run follows four steps.

01 · Fetch

Each node queries the ACRIS Legals dataset for the BBL, then Master for document types, 80 IDs at a time.

02 · Agree

Nodes reach identical consensus on the sorted document list.

03 · Classify

The adverse map splits documents into adverse, discharge and other.

04 · Report

A signed report goes to the token through the forwarder.

// workflow/workflow.ts (excerpt)
const fetchDocs = (req, config) => {
  const legals = get(legalsUrl(config.bbl));
  for (chunk of ids, 80 at a time)
    master.push(...get(masterUrl(chunk)));
  return JSON.stringify(canonicalDocs(legals, master));
};

assertComplete(rows);  // 5,000-row cut-off: refuse

Run it yourself.

# CRE simulation (needs: cre login, bun on PATH)
cre workflow simulate ./workflow -T staging-settings --non-interactive --trigger-index 0

05 · limits

Where it stops.

LIMIT 01
Lag

ACRIS records filings days after the real event. Early warning, not a title search.

LIMIT 02
One source

Every node reads the same public API. A second source is a stretch goal.

LIMIT 03
Testnet

The demo token accepts the simulator's public placeholder owner. Production needs a deployed workflow.

LIMIT 04
Issuer power

The issuer can clear a restriction. It has to do it publicly and name the liens it reviewed.

LIMIT 05
Not legal advice

A hackathon build. It flags public filings; it does not judge their legal effect.
